核心功能

为高效而生,为隐私而存

从底层剪贴板监听到键盘级的极速操作,每一处细节都经过打磨。

实时监听

后台静默监听剪贴板变化,自动记录文本与图片历史,无需手动保存,所见即所得。

模糊搜索

智能分类与即时模糊搜索,数千条历史也能瞬间定位。链接、文本、图片各归其位。

全局快捷键

一键呼出 / 隐藏窗口,全程键盘导航。1–9 数字键直接快速粘贴,手不离键盘。

本地持久化

JSON 文件原子写入,图片外置独立存储、按需加载。重启不丢数据,告别云端依赖。

托盘常驻

系统托盘常驻后台,可选开机自启与静默启动,始终待命却不打扰你的工作流。

隐私优先

完全本地运行,不联网、不上传、不追踪。你的剪贴板历史只属于你自己。

界面一览

一眼看清,一步到位

分类、搜索、导航、粘贴——四步并作一步,键鼠皆可,直觉即操作。

  1. 01

    彩色分类标签

    六类内容(全部 / 图片 / 文本 / 链接 / 短文本 / 富文本)各以独立色彩标识,筛选只需一点。

  2. 02

    即时模糊搜索

    边输入边筛选,结果实时更新,数千条历史也能在毫秒间收敛到你想要的那一条。

  3. 03

    序号 + 键盘导航

    每条记录自带 1–9 序号,按数字键直接快速粘贴;↑/↓ 浏览,Enter 复制。

  4. 04

    状态栏实时反馈

    底部状态栏显示监听状态与操作提示,所见即所控。

键盘至上

手不离键盘,全程丝滑

所有操作皆可键盘完成,呼出、搜索、导航、粘贴一气呵成。

呼出 / 隐藏窗口(可在设置中修改)Ctrl+Shift+V
列表上下导航↑/↓
复制选中项到剪贴板Enter
数字键快速粘贴并置顶该条1–9
