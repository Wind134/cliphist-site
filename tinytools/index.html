WHAT IT DOES

少切几个窗口，
多掌握一点系统状态。

为开发、运维和日常排障准备的常用能力，不堆功能，只解决高频问题。

SSH TUNNEL MANAGER

稳定管理多个 SSH 隧道

集中创建、编辑、批量启停反向隧道；支持密码与 OpenSSH 私钥认证，并在网络波动后自动尝试重连。

本机端口→SSH Server→远端服务
PORT INSPECTOR

端口被谁占用，一眼看清

查看 IPv4/IPv6 TCP 监听和连接，按端口、PID、进程名或地址快速筛选。

FILE LOCK VIEWER

删不掉的文件夹，找到真正占用者

选择或拖入文件、文件夹，递归定位目录内被占用的文件，并合并展示相关进程。

＋拖入文件或文件夹安全递归扫描 · 结果自动去重

统一主题、托盘与启动行为

浅色、深色或跟随系统；配置默认页面、关闭行为、退出确认、托盘通知与自动刷新。

LOCAL BY DESIGN

敏感配置，应该留在你的电脑里。

TinyTools 不要求云端账号。SSH 主机地址与密码使用 Windows DPAPI 加密，并绑定当前 Windows 用户；私钥只记录路径，不复制密钥文件。

  • 01
    Host Key 校验首次确认指纹，后续连接自动核验，降低中间人攻击风险。
  • 02
    原子配置保存写入前保留备份，通过临时文件替换，减少配置损坏风险。
  • 03
    关键进程保护终止系统关键进程前给出明确警告，避免误操作。
